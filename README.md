# technical_support_performance_dashboard
Dataset performing cleaning analising and preparing a dynamic dashboard in excel


## 📁 Data
- **`/data/raw/`**: Original dataset downloaded from Kaggle. No modifications.
- **`/data/processed/`**: Cleaned dataset with:
  - Binary SLA flags.
  - Filled missing values for close/resolution times.
  - Added `Quarter` and `LOB` columns.
- **`/dashboards/`**: Excel dashboard with visualizations.
- **`/supporting_files/`**: Pivot tables and additional reports.
